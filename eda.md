# IT Salaries Data Analysis (EDA Project)

This project presents an exploratory data analysis (EDA) of compensation data in the IT industry.  
It was completed as part of the self-paced **Data Science program at nFactorial School (2025)**.

## 📌 Description

The dataset contains information on salaries, bonuses, stock options, job levels, education, experience, and more.  
The main goal of this project is to identify patterns and trends in employee compensation across different groups.

## 🧠 Skills Applied

- Data loading and preprocessing
- Descriptive statistics and aggregation
- Grouping and filtering with pandas
- Visualization of distributions and relationships
- Drawing insights and writing conclusions

## 🔧 Technologies Used

- Python
- pandas
- numpy
- matplotlib / seaborn
- Jupyter Notebook

## 📊 Dataset

- `P01_Salaries_Dataset.csv`  
An anonymized dataset provided by nFactorial School for educational purposes.

## 📝 Results

The notebook contains:
- Salary comparison by experience and education
- Bonus and stock option distribution
- Visualization of correlations
- Key takeaways and EDA conclusions

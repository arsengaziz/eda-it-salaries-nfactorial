# Exploratory Data Analysis: IT Salaries

This project is a part of the **nFactorial School's Data Science program (2025)**.  
It showcases exploratory data analysis (EDA) on a dataset of IT specialists’ salaries.

## 📊 Project Goals

- Clean and preprocess the dataset
- Explore distributions and salary trends
- Analyze the impact of location, experience, and remote work on compensation
- Visualize key insights with plots

## 🛠️ Tools & Technologies

- Python  
- Pandas   
- Jupyter Notebook
